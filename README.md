# 📚 Biblioteca API

Projeto desenvolvido para colocar em prática conceitos de **desenvolvimento web, APIs e banco de dados**.

## 💡 Sobre o projeto

A proposta é criar um sistema simples para gerenciamento de livros, permitindo **cadastrar, consultar, editar e excluir** livros de uma biblioteca.

A aplicação será dividida em três partes:

**Front-end → API → Banco de Dados**

O usuário realizará as ações pela interface, a API processará as informações e o banco de dados ficará responsável por armazená-las.

## 🛠️ Tecnologias

- **Python + FastAPI** — desenvolvimento da API
- **MySQL** — banco de dados
- **SQLAlchemy** — conexão com o banco
- **HTML, CSS e JavaScript** — interface
- **Git e GitHub** — versionamento do projeto

## 🎯 Objetivo

O objetivo é desenvolver uma aplicação funcional e entender, na prática, como **Front-end, Back-end, API e banco de dados** se comunicam para formar um sistema completo.
